## Native window observations in this session

The staged debug executable and real DLL were operated through Computer Use (SendInput and window capture) at 125%. These are actual native-window observations, not physical-key or presentation-latency measurements. Microsoft YaHei and Segoe UI Emoji were loaded from the system; CJK and combining text were visible, while some emoji/flag/keycap/ZWJ forms displayed components or placeholders.

The test fixture was `hello 你好 straße🙂 é 👩🏽‍💻 🇨🇳 1️⃣`, followed by a real CRLF and `第二行 🧪`. Clipboard ownership was replaced with a unique sentinel before each copied/cut assertion, preventing stale source contents from falsely passing.

1. Ctrl+A/V replaced the initial scratch contents: 77 UTF-8 input bytes became 76 LF bytes, revision 2. Ctrl+A/C returned the exact LF fixture.
2. Ctrl+Shift+U invoked the loaded DLL and produced `HELLO 你好 STRASSE🙂 É 👩🏽‍💻 🇨🇳 1️⃣` plus the unchanged second line, 76 bytes, revision 3. Ctrl+Z restored the original bytes and whole selection at revision 4. Ctrl+Shift+Z restored the uppercase bytes/selection at revision 5. All three clipboard assertions matched exactly.
3. A new scratch tab in Microsoft Notepad 11.2607.14.0 received the uppercase text. Copying it back produced exactly the expected 77-byte CRLF form. Pasting into RustEditor normalized it to the same 76-byte LF form; copying back matched exactly. Identical replacement left revision 5 unchanged. Other pre-existing Notepad tabs were not edited.
4. Ctrl+X copied all 76 bytes and left an empty document at revision 6. Ctrl+V restored 76 bytes at revision 7.
5. Alt+F4 opened the discard prompt. Keep editing retained the visible text, 76-byte count and revision 7. The titlebar close button also prompted; Discard and close terminated the task's editor process. The temporary Notepad test tab was closed without saving; pre-existing tabs remained open.

## GUI/ABI decision and follow-up

Retain eframe/egui 0.33.3 with native Glow for M1, based on passing automated/plugin checks, the scoped native observations and the maintainer's acceptance instruction. Retain the current experimental v1.0 C ABI with version, size, capability, buffer, revision, panic, thread and lifecycle checks. Historical SDK compatibility and hot unloading remain out of scope. This sign-off does not claim a new rendering implementation or a stable cross-version SDK.

The 4 MiB String/full-document galley, 256-entry/8 MiB undo bounds, synchronous short plugin commands, incomplete emoji shaping and small idle-memory margin remain prototype limitations. Recollect the full native scenario matrix and synchronized startup/input-display evidence when doing further GUI/performance work; preserve exact builds, raw samples, uncertainty and missed budgets. File I/O, tabs, recovery and large-file modes remain later milestones.
