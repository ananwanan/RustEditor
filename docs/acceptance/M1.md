## M1.1 Bounded UTF-8 File Opening

The desktop opens one regular file supplied as `--open PATH`. File I/O reads at most 4 MiB plus one byte to detect overflow, even if a file grows after metadata is checked. It rejects unsupported BOMs and invalid UTF-8. Valid bytes, including LF and CRLF, enter the existing core Document unchanged. The view and plugin host share that document. The toolbar displays the filename and **Read from disk · Saving not yet available**.

The read uses a read-only handle before the window is created. Edits and plugin transactions affect the in-memory document. Close confirmation protects sessions after an edit, including when undo returns to the initial text. This is session protection. M1.2 will establish a saved baseline for modified-state tracking.

### Windows GUI checks

The local debug window reported 125% scale. The debug executable SHA-256 was `ba10d6c7f6b5d75cf7fc8011724c1e662c60d4d10d4d9d89b856c0f89097a4ec`. Run from the repository root.

```powershell
cargo xtask stage
cargo run --locked -p rusteditor-desktop -- --no-plugins --open ".\tests\fixtures\probe.rs"
cargo run --locked -p rusteditor-desktop -- --open ".\tests\fixtures\probe.rs"
```

1. Without plugins, the window showed `probe.rs`, the saving notice, zero plugins, and the fixture at 4,121 bytes. Inserting `你好🙂 é ` at the start increased the length to 4,136 bytes. Ctrl+Z restored the original first line and length. Ctrl+Y restored the insertion. Alt+F4 displayed the discard prompt, **Keep editing** retained the edit, and **Discard and close** exited.
2. With plugins, the window showed one native plugin. Shift+End from the initial caret selected the 88-byte first line. Ctrl+Shift+U uppercased that selection. Ctrl+Z restored its original case and Ctrl+Shift+Z reapplied the transformation. Discarding the test edits closed the window.
3. The source file SHA-256 matched before and after both sessions, `634b8b431d5f4553ebe4efa057ba7f26318efe383f392c580597ae2b85cdd827`.

This session used literal Unicode input. Native IME composition, clipboard interoperability, additional DPI scales, and other operating systems were outside this focused GUI run. ## Remaining M1 Work

M1.2 adds Save and Save As, a saved baseline independent of monotonically increasing revisions, immutable save snapshots, platform-validated replacement, and Save/Discard/Cancel. Its failure cases include locks, read-only destinations, and failed writes that must preserve the original. M1.3 adds tabs, M1.4 adds line numbers and the editing UI, and M1.5 verifies the complete workflow. Encoding conversion, recovery, and large-file mode follow their own roadmap gates.
